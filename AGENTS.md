## Shared instructions

At the start of a task, read and follow the [central loading instructions](https://github.com/ksteverding/agenticCoding/blob/main/instructions/start.md). Prefer the local file at `$AGENTIC_CODING_HOME/instructions/start.md`, or `~/.local/share/agenticCoding/instructions/start.md` when that variable is unset. If a global instruction already loaded a central revision for this task, reuse it. Keep the project-specific rules in this file; they take precedence over shared defaults.
