# TronTowerDefense
A fun little vibe coded tower defense game. My custom Benchmark for testing new models.

`main` opens on a **model-select splash screen** — a benchmark hub that lets you pick
which AI model's build of the game to boot. Selecting a model jumps to that model's own
game splash screen and plays its version of GRID DEFENSE.

The first available build was generated by **Claude Fable 5** (`claude-fable-5`) at
**low reasoning effort** in a single turn, and is also tagged as `fable-5-low-effort`.
The exact prompt given to every model is in [PROMPT.md](PROMPT.md), and the rules
and workflow for running the benchmark with a new model are in [BENCHMARK.md](BENCHMARK.md).
Each run lives on its own branch/tag so any two attempts can be diffed directly.

Adding a model to the hub is a one-line change: append an entry to the `MODELS` array
near the top of `game.js`. Each entry sets `available: true` with `target: 'splash'`
for a build bundled in this page, or an `href` to open an externally hosted build.

To play: open `index.html` in a browser (fully static, no build step).
